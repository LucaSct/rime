# ADR-0064 (m19.5): Terrain shades with the shared GGX BRDF, and metallic/roughness join the splat blend

- Status: Accepted
- Date: 2026-10-05

## Context

ADR-0062 drew the terrain with Lambert shading because that was the smallest honest picture, and
ADR-0063's addendum narrowed the splat blend to base colour for the same reason: a blended
`metallic` or `roughness` would have been data nothing read. Both were named as deferrals. The
goal of m19.5 is the "metallic look" — terrain that can carry a metal layer — which needs the
shading and the blend to move together.

## Decision

### 1. Terrain uses the same BRDF as `pbr_forward.frag`, from one shared include

`d_ggx`, `v_smith_ggx`, `f_schlick` and `shade_light` moved verbatim into
`engine/render/shaders/brdf.glsl`; `pbr_forward.frag`, `pbr_forward_shadowed.frag` and
`terrain.frag` include it. The shader build already tracks included files through glslang's
depfile. This supersedes ADR-0062's Lambert shading; the faceted-normal logic is unchanged.

### 2. Metallic and roughness join the splat blend (reversing ADR-0063's addendum narrowing)

`TerrainLayer` gains `metallic` (default 0) and `roughness` (default 1); `TerrainLight` gains the
same pair as the flat (v1) tile's material. Both are blended in the **same difference form** as
base colour, so the bit-identical anchor (four equal layers == the flat tile) still holds with no
margin. Unused slots repeat layer 0, a zero difference. `upload()` refuses and counts (in
`splat_refused()` and `tiles_refused()`) a non-finite value or one outside [0,1] — it never clamps
a caller's mistake into a plausible picture. The shader then clamps roughness to [0.045, 1] and
uses `alpha = roughness²`, as `pbr_forward` does.

### 3. The push block is 160 bytes, behind a counted capability check

`TerrainPush` grows from 128 to 160 bytes (`eye`, `material`). Vulkan guarantees only 128, so
`rhi::AdapterInfo` gains `max_push_constant_bytes` (from `maxPushConstantsSize`; default 128). A
device below `sizeof(TerrainPush)` makes every `upload()` refuse: counted in `tiles_refused()` and
warned once naming both numbers (ADR-0039's rule — fail counted, never silently). The splat
constants stay in the uniform block (now 112 bytes: `color[k].w` = metallic, plus a `roughness`
vec4). The API takes the camera position explicitly: `terrain_push(tile, view_proj, eye, light)`
and `TerrainPass::add(..., view_proj, eye, light)`, because an orthographic `view_proj` cannot
yield one.

### 4. The palette is resolved by the builder

The caller of `upload` — the "builder" — turns each `HeightfieldAsset::layers[k]` into a
`TerrainLayer`; the pass still does not reach into the asset system. Confirmed by Luca on
2026-10-05.

### 5. Ambient is a uniform-environment stand-in, and it has limits

`radiance += ambient * ((1 - metallic) * base + f0)`, `f0 = mix(0.04, base, metallic)`. This is
what a uniform white environment would contribute, used until terrain reads the sky SH. It is
**not** the old Lambert ambient (`base * ambient`): a dielectric now gets `ambient * (base + 0.04)`.
A flat-ambient metal reads darker than a real one because a real metal mirrors the sky and
horizon, which needs an environment reflection this brick does not have.

## Consequences

- `shade_light`'s diffuse is `kd * albedo / π` with `kd = (1 - F) * (1 - metallic)`, so even a
  metallic-0 terrain is slightly **darker** in its diffuse than m19.3's `albedo / π` (by the
  Fresnel term, about 4% head-on) and gains a specular lobe. The m19.3 analytic-Lambert test still
  passes, but only through doctest `Approx`'s unit scale: measured worst relative error went to
  9.9% against its stated 1% intent, so that test no longer pins Lambert tightly.
- Proofs (`m19.5:` cases): equal metallic layers bit-identical to the flat tile; metallic and
  roughness each reachable through the blend; a metal's highlight G/R (0.125) below a
  dielectric's (0.90); a rough metal's peak strictly below a smooth one's; out-of-range and NaN
  materials refused and counted. Falsified: metallic from layer 0 only, `f0` forced to 0.04 and a
  constant `alpha` each turn the matching case red.

## Deferred

- Sky-SH / IBL reflections, which replace the ambient stand-in.
- Per-layer textures (albedo/normal/ORM maps); layers are still constants.
