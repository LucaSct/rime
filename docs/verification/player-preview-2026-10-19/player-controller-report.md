# Preview player controller leaf

Commits: `59d8b9a` (adapter/host wiring), `35e87e3` (format, admission hardening and 15 focused CPU tests), `51aa394` (exact authored ground support/control). Base `7be38d2`, branch `feat/preview-player-controller`, isolated worktree `/home/next/projects/rime-wt/preview-player-controller`.

`block_editor::PreviewPlayer::hooks()` supplies Begin/tick/transition. State, look, input latches and owned resource ids stay outside ECS. Exactly one valid enabled PlayerSpawn and one active, transformed, unparented camera are required. Begin uses the real PhysicsWorld penetration query to refuse overlap. Tick uses existing `step_character`, `apply_look` and `eye_transform`; LocalTransform and WorldTransform camera poses are written together. Pause/Resume/ReleaseInput clear held intent and horizontal velocity without requiring a tick. Stop destroys owned bodies before unregistering hulls, before the host destroys physics; fresh Begin resets state even at an identical pose. Foreign session callbacks are ignored.

Source collision is a fixed snapshot for the Player session: root will refuse authoring mutations and saving while possessed; Inspect retains authoring behavior. Ground and PhysicsSync-owned live bodies are reused, never duplicated/destroyed. Known CookSpec geometry uses its actual source box dimensions. Generated lamp/barrier parts use their actual convex source vertices, scaled before hull registration with COM compensation; matching scaled patterns share hulls. Unit-cube kerb/barrier/lamp/timber roles use their actual transformed unit geometry. Light-only roles are explicitly non-solid. No generic bounds guessing, giant floor, authored collider writes or network actor.

Bounds: 2048 owned static bodies, 128 hulls, 32 distinct scaled generated patterns; world coordinates/positive scale/dimensions bounded to 8192, minimum positive dimension 1e-4. Rotations and positive nonuniform scales supported; parented geometry and camera, negative/zero/nonfinite scales, unknown assets/imported meshes/missing collision sources, inconsistent cooked-vs-unit-prop roles, bad camera/spawn and authored heightfields explicitly refuse. Refusals after partial allocation clean all owned resources. Unsupported heightfield-query encounters/nonfinite movement halt the controller with diagnostics. Preview does not push crates, shoot, damage, swim, fracture or provide network authority. It does not silently recover out-of-bounds falls.

16 tests cover wall-versus-absent sensitivity; real floor settling/jump; look; pause/release/focus; source sizes/rotation; lamp empty-space versus hull control and resource sharing; partial cleanup; body cap; bad spawn/camera/scale/parents; existing host collision ownership; imported/terrain refusal; camera removal; foreign sessions; actual PlaySession Stop serialization roundtrip and fresh session reset.
