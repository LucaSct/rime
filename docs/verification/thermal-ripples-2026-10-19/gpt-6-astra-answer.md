**Minimum safe day-end design:** keep geometry fixed and treat this strictly as cosmetic appearance. Do not imply flow, thickness, displacement, or physical ice authority.

- **Start simpler:** improve ice RGB/roughness first, then add a small periodic normal-map animation for liquid. Defer base-texture overrides/icy veins unless normal detail alone remains visually ambiguous. Thirty-two 128² frames are reasonable, but discrete frame changes may shimmer; use fewer only after visual validation. True frame blending would expand shader scope—avoid it today.
- **API:** extend the existing generation-safe appearance rows with optional borrowed normal-map and normal-scale overrides. Preserve the distinction between “inherit material texture” and “explicitly clear texture.” Apply overrides only to the renderer’s private, resolved per-draw material; never mutate shared assets. Cover every submesh. At liquid fraction zero, force ripple scale to zero rather than merely stopping animation.
- **Time:** derive phase from committed accepted simulation time. `accepted_host_tick × dt` is valid only with fixed timestep and a defined epoch; otherwise accumulate accepted simulation durations. Never use render wall time or resettable field tick. Publish fraction and time atomically as one committed snapshot. Pause and failed steps preserve appearance; define rebuild as either explicit phase reset or preserved phase, keyed by generation.
- **Lifetime:** a removable `fluids_render` owner uploads immutable maps during initialization. The device outlives it; it outlives renderer references **and pending GPU work**. Removal must first withdraw overrides, then retire textures after completion. Borrowed pointers alone do not ensure this.
- **Fallback:** create the entire animation set transactionally. On allocation/upload failure, release partial resources safely and use RGB/roughness-only appearance. Never publish incomplete frames or dangling handles.

**Strongest tests:** deterministic offscreen pixels with fixed camera, lighting, exposure, and committed state. Verify liquid changes across accepted times; pause/failure and fully frozen snapshots remain pixel-identical; zero-liquid ripple output equals the ripple-disabled reference. Exercise forward and G-buffer paths, textured multi-submesh meshes, generation reuse, rebuild, and injected upload failure. Require bit-identical depth/shadow outputs against baseline; include unmodified neighboring objects to catch override leakage. Static frozen veins, if added, must not advance with phase.
