## Orchestrator's verification pass (Opus, 2026-10-11)

Verified every claim against the code rather than taking the report. What changed as a result:

**A real bug the report filed as a caveat.** Its last line read *"under a budget below 6, the first
build leaves the unserviced layers uninitialised until later frames fill them."* That is not a
caveat — `ensure_resources` creates the array with `create_texture` and **no clear**
(`sky_specular.cpp:134`, `prefiltered_state_ = Undefined`), and the forward pass samples **every**
layer whatever the budget is. So turning the knob below 6 would have sampled uninitialised device
memory for the first frames, and no counter would have shown it.

Fixed with a second mask, `prefilter_written_mask_`, distinct from the validity mask and cleared only
when the texture is created: a **stale** layer is deferrable (it holds a slightly older sky, which is
the budget's whole correctness argument), a **never-written** layer is not. The first build therefore
fills the whole chain however small the budget, and the default path is unchanged.

**Falsified.** Mutating the bypass away (`selected = 0`) fails the new case on all three of its
assertions, and the third is the one that proves the hazard was real rather than theoretical:

    prefilter_layers_filled   1 vs 6
    prefilter_partial_frames  1 vs 0
    layer content             17.6094 vs < 0.001   <- an unwritten layer really does hold garbage

Reverted; `grep -c MUTATION` = 0, rebuilt, 5/5 budget cases pass.

**The two gates the agent could not run, run here.** `ctest --preset dev -R render` exit **0**,
14/14, 93.8 s — the report gave the result without the exit code. clang-format over CI's **full**
`find` set (refused by the agent's sandbox) exit **0**, and it changed no file the agent had not
already formatted, so its partial pass was adequate for the rest of the tree.

**Case count.** 15 `sky specular*` cases in the fresh binary, 15 in the file (10 + the agent's 4 +
this one), 592 assertions, exit 0. 187 cases in `rime_render_tests` overall. Nothing was silently
skipped. (A `grep` for `TEST_CASE("sky specular` counts only 14 — one case's name begins on the
following line. The binary's own listing is the authority.)

**Also fixed:** the stale comment the report flagged and left alone (the scrolling-cloud case still
claimed "ONE `prefilter_valid_` flag"). It now says why that case deliberately keeps the default
budget: it measures what a rebuild *costs*, which is the input to choosing a budget, so it must not
itself be throttled by one.

**Pre-existing, NOT introduced here, and not fixed here.** All five new cases emit
`vkCmdWriteTimestamp2(): query not reset` Vulkan validation errors. So does the #297 scrolling-cloud
case already on `main` (10 of them), and "no seam" (2). The cause is the `Rig`'s
`cmd->write_timestamp(0)` at `tests/render/sky_specular_test.cpp:338` with no pool reset; this branch
does not touch the `Rig`, `bake()` or the timestamp path (verified with `git diff origin/main..HEAD`).
Worth its own brick — validation noise is how a real validation error gets missed — but widening
scope into it here was explicitly forbidden.

**Accepted as-is:** brace-less single statements match the house style (`ddgi.cpp` has 10,
`sdf_clipmap.cpp` 14) and clang-format does not insert braces. (d) using the test `Rig` rather than
`SceneRenderer::Output::sky_prefiltered` is fine — there is no budget setter on the renderer, and it
reads the same `SkySpecular::prefiltered()` texture the renderer exports.
